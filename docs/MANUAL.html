CHAPTER 01 / START HERE

はじめるまで、
3つの動作。

モデルのダウンロードもGPUも不要。最初の一度だけ、元のPyBotの公開ソースを取得します。

01DOWNLOAD

アプリを取得

pybotDemoリポジトリから Code → Download ZIP。展開したフォルダを開きます。

02ONE CLICK

起動ファイルを開く

Macは start_mac.command、Windowsは start_windows.bat をダブルクリック。

03EXPLORE

ブラウザで質問

アプリがブラウザで開きます。「名前と記憶」のシナリオを選んで送信すれば準備完了。

MacmacOSの保護が初回実行を止めたときは、ファイルを右クリック→「開く」。実行できない場合は python3 launch.py でも起動可能です。
WindowsPython 3.8以上が必要です。Windowsのターミナルから py -3 launch.py でも起動できます。
初回はインターネット接続が必要です。取得したPyBotは .runtime/pybot に保存され、通常2回目以降は再取得しません。PyBot自体の会話処理には外部LLM APIを使用しません。

GoogleのTranslator API公式資料 ↗　翻訳には誤訳の可能性があります。原文の英語・実際に渡した英文も確認しながら、PyBotの能力と翻訳の効果を分けて議論してください。

!

プライバシーと対応ブラウザ
文字起こしにはブラウザ標準のSpeechRecognitionを使用します。音声がブラウザ提供元のサービスに送られる場合があるため、完全オフラインの音声認識とは保証できません。PyBot本体は音声データを受け取らず、認識後の文字だけを扱います。非対応ブラウザではMacの音声入力、Windowsの Win+H を使えます。

CHAPTER 04 / EXPERIMENT

正解を探すより、反応の違いを楽しむ。

質問を少し変えたとき、採択候補と内部のルールはどう変わるでしょうか。以下の3つが入口です。

01 / MEMORY初級・上級共通

名前を覚えているように見える？

Hi, I'm Sam.What's my name?Actually, my name is Alex.

何を「記憶」して、何を文字列として扱うのか。メモリの変化と採択候補を照らし合わせます。

02 / GENERALIZATION言い換え比較

同じ意味、違う言い方。

How long should I boil an egg?What's the best way to cook eggs in water?

候補モジュールの重なりが変わったら、なぜか。LLMの汎化能力と比較する際の起点になります。

03 / UNKNOWN INPUT弱点を探す

知識にないことを尋ねる。

Explain Quantum Banana Regression.こんにちは、名前を覚えられますか？

架空の概念や言語の違いに対し、ルールはどこまで対応できるでしょうか。

CHAPTER 07 / HELP DESK

困ったときの、最短ルート。

日本語ブリッジのボタンが使用できない

ブラウザにオンデバイスTranslator APIがない、または必要な言語パック・環境条件を満たしていない可能性があります。Chrome 138以降のデスクトップ版、対応Edgeをお試しください。利用できない場合でもPyBot純正の英語会話やソース追跡は利用できます。翻訳機能はPyBotの実力とは分けて評価してください。

MacでSSL証明書エラーが出て起動できない

Python.org版Pythonで初回の `CERTIFICATE_VERIFY_FAILED` が起こる場合があります。Live Labはこの場合だけ、macOS標準のcurlを使って証明書を検証したまま安全に再試行します。解消しないときはFinderの「アプリケーション → Python 3.13 → Install Certificates.command」を実行し、改めて起動してください。Pythonのバージョンが異なる場合は対応するフォルダを選びます。証明書の検証を無効化する方法は使わないでください。

ライト／ダークを切り替えたい

アプリ右上の「ライトへ」「ダークへ」を押します。次回以降は選択した表示テーマをこのブラウザ内に保存し、会話データとは別に扱います。

CSSや画像が表示されない

この配布版 MANUAL.html はCSSと実スクリーンショットを同梱した単体ファイルです。ブラウザで直接開いてください。もしリンクが生きない場合も、本文・図解はネット接続なしで読めます。

マイクボタンが使えない

ブラウザによりSpeechRecognitionが利用できない場合があります。Macの音声入力、Windowsの Win+H を試してください。マイクの許可も確認します。

Pythonが見つからない

Python公式サイトからPython 3.8以上を導入してください。アプリの本体には追加pipパッケージはありません。

最初の回答が遅い

初回は大量のPythonルールを読み込みます。LLMの重みをロードしているわけではありません。

再実行のトレースが元と違う

文脈や乱数、内部状態により再実行の結果が変わる場合があります。画面に「不一致」と出たら、その通過行を元の実行の証拠として扱わないでください。

PyBotの正式な論文はある？

2026年11月18日時点で確認した一次情報ではPyBot専用の査読論文・公式ホワイトペーパーは確認できません。公式のREADME、コード、評価データ、性能推移図が主な資料です。
